## Featured Projects

### RepoGraph

A local-first code intelligence CLI/TUI for understanding large codebases.

**What it does:**

- Indexes Python and JavaScript/TypeScript repositories
- Builds a queryable SQLite-backed dependency graph
- Supports repository search and file explanation
- Detects import cycles and possible dead code
- Performs direct and indirect impact analysis
- Provides PR risk scoring from local Git diffs
- Includes a Textual-based terminal UI

**Tech:** Python, SQLite, Typer, Textual, AST, Git

[View Repository](https://github.com/MalayChhatbar/Repograph)

---

### ReproRun

A deterministic command runner for reproducing flaky tests, cache bugs, and local/CI mismatches.

**What it does:**

- Runs commands with controlled execution inputs
- Uses strict YAML config loading
- Supports deterministic environment controls
- Captures stdout/stderr and exit codes
- Uses BLAKE3-based run hashing
- Provides local content-addressed artifact caching
- Supports reproducibility checks, run diffs, and cache inspection

**Tech:** Rust, CLI, YAML, BLAKE3, Git, Caching

[View Repository](https://github.com/MalayChhatbar/ReproRun)
